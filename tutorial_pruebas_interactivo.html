Tutorial de Pruebas del Sistema HL7 MDM/ORM

Puedes alternar fondo claro u oscuro según tu preferencia visual o necesidades de dislexia.

Pruebas de Procesos MDM

1 Preparar el entorno
  • Abre una terminal en la carpeta del proyecto HL7FINAL.
  • Crea y activa un entorno virtual (recomendado):
Linux/Mac: 
python3 -m venv venv
source venv/bin/activate
Windows (CMD): 
python -m venv venv
venv\Scripts\activate
  • Instala las dependencias:
pip install -r requirements.txt
pip install PyQt5
2 Iniciar el servidor MLLP del HIS (recibe cualquier mensaje HL7)
  • En una terminal, activa el entorno virtual y ejecuta:
Linux/Mac: 
source venv/bin/activate
python3 mllp_his/servidor_mllp_his.py
Windows (CMD): 
venv\Scripts\activate
python mllp_his/servidor_mllp_his.py
Este servidor ahora recibe cualquier tipo de mensaje HL7 (MDM, ORM, etc.) enviado al HIS, usando la configuración MLLP_HIS de config_db.py.
IP configurada para RIS/PACS: 172.16.60.71 (ver config_db.py).
3 Enviar mensajes MDM de prueba al HIS
  • Abre otra terminal, activa el entorno virtual y ejecuta el cliente MDM:
Linux/Mac: 
source venv/bin/activate
python3 mdm/mdm_cliente_envio.py
Windows (CMD): 
venv\Scripts\activate
python mdm\mdm_cliente_envio.py
El cliente MDM envía mensajes HL7 MDM^T02 al servidor HIS usando la configuración MLLP_HIS. Observa los mensajes y ACKs en ambas terminales.
4 Verificar los mensajes en la base de datos
  • Conéctate a Oracle y ejecuta:
SELECT * FROM SEGMENTOS_HL7.MENSAJES_MDM ORDER BY ID DESC;
Confirma que los mensajes recibidos se almacenan correctamente.
¿Qué es un mensaje MDM^T02?
El mensaje HL7 MDM^T02 se utiliza para transmitir documentos médicos, informes y archivos (por ejemplo, PDF en base64) entre sistemas HIS y RIS/PACS.
Ejemplo Ejemplo de mensaje HL7 MDM^T02 
MSH|^~\&|SISTEMA|SISTEMA|VMGESTION|VMGESTION|20240620100000||MDM^T02|123456789|P|2.7|||||||UNICODE UTF-8
PID|||12345678^^^^DNI||PEREZ^JUAN|GOMEZ|19800101|M|||AV. SIEMPRE VIVA 123||1122334455|
OBR|1|78910||RX001^RADIOGRAFÍA DE TÓRAX|||20240620100000|||||||||||||||||CR
OBX|1|ED|PDF^Informe|1|JVBERi0xLjQKJcfs... (PDF en base64) ...==|...|
Tips de integración y errores comunes:
  • El campo OBX-5 puede contener archivos PDF en base64.
  • Verifica que el PDF se almacene correctamente en Oracle (campo CLOB).
  • Revisa el ACK recibido para confirmar la recepción exitosa.
  • Si no recibes ACK, revisa el puerto, firewall o formato del mensaje.
  • Consulta la estructura de la tabla MENSAJES_MDM en el README para mapear los campos.

Utilidades y Validación

1 Validar mensajes HL7 manualmente
  • Activa el entorno virtual y ejecuta el validador gráfico:
Linux/Mac: 
source venv/bin/activate
python3 validador_hl7.py
Windows (CMD): 
venv\Scripts\activate
python validador_hl7.py
Pega un mensaje HL7 para validarlo, autocorregirlo o compararlo con ejemplos.
2 Detener procesos de prueba
  • Para finalizar los procesos de prueba, puedes usar:
Linux/Mac: 
./kill_mllp_siu_mdm.sh
Windows (CMD): 
taskkill /IM python.exe /F
En Windows, puedes cerrar los procesos Python desde el Administrador de tareas o usando el comando anterior (esto detiene todos los scripts Python activos).
¡Listo! Has completado las pruebas básicas del sistema HL7 MDM/ORM.

Pruebas de Procesos ORM

1 Iniciar el servidor MLLP del RIS/PACS (recibe cualquier mensaje HL7)
  • En una terminal, activa el entorno virtual y ejecuta:
Linux/Mac: 
source venv/bin/activate
python3 mllp_rispacs/servidor_mllp_rispacs.py
Windows (CMD): 
venv\Scripts\activate
python mllp_rispacs/servidor_mllp_rispacs.py
Este servidor ahora recibe cualquier tipo de mensaje HL7 (ORM, MDM, etc.) enviado al RIS/PACS, usando la configuración MLLP_RISPACS de config_db.py.
2 Enviar mensajes ORM de prueba al RIS/PACS
  • Abre otra terminal, activa el entorno virtual y ejecuta el cliente ORM:
Linux/Mac: 
source venv/bin/activate
python3 orm/orm_cliente_envio.py
Windows (CMD): 
venv\Scripts\activate
python orm\orm_cliente_envio.py
El cliente ORM envía mensajes HL7 ORM^O01 al servidor RIS/PACS usando la configuración MLLP_RISPACS.
IP configurada para RIS/PACS: 172.16.60.71 (ver config_db.py). Observa los mensajes y ACKs en ambas terminales.
3 Verificar los mensajes en la base de datos
  • Conéctate a Oracle y ejecuta:
SELECT * FROM SEGMENTOS_HL7.MENSAJES_ORM ORDER BY ID DESC;
Confirma que los mensajes ORM enviados y recibidos se almacenan correctamente.
¿Qué es un mensaje ORM^O01?
El mensaje HL7 ORM^O01 se utiliza para transmitir órdenes médicas y solicitudes de estudios. Es el estándar para la integración entre sistemas HIS y RIS/PACS.
Ejemplo Ejemplo de mensaje HL7 ORM^O01 
MSH|^~\&|SISTEMA|SISTEMA|VMGESTION|VMGESTION|20240620100000||ORM^O01|123456789|P|2.7|||||||UNICODE UTF-8
PID|||12345678^^^^DNI||PEREZ^JUAN|GOMEZ|19800101|M|||AV. SIEMPRE VIVA 123||1122334455|
PV1||O||||||12345^LOPEZ^CARLOS|||||||||||78910
IN1|1|PLAN_OSDE||OSDE
ORC|NW|78910|||||20240620100000|
OBR|1|78910||RX001^RADIOGRAFÍA DE TÓRAX|||20240620100000|||||||||||||||||CR
Tips de integración y errores comunes:
  • El servidor dump es solo para pruebas. En producción, el destino será el RIS/PACS.
  • Verifica siempre el ACK recibido para confirmar la recepción exitosa.
  • Revisa que los datos enviados correspondan a una orden real y completa.
  • Si no recibes ACK, revisa el puerto, firewall o formato del mensaje.
  • Consulta la estructura de la tabla MENSAJES_ORM en el README para mapear los campos.
